| # | Ejercicio | Error | Frase para recordar |
|---|---|---|---|
| 1 | P07 | `precio * 0.82` para quitar el IGV | 🧾 *"Para quitar el IGV, divides."* → `precio / 1.18` |

| 3 | P08, P18 | Faltaba `;` | ⏹️ *"El punto y coma es el punto final."* |
| 4 | P25, P27, P28 | `ROUND` dentro del `WHERE` | 📸 *"Filtra con lo exacto, redondea solo para la foto."* |
| 5 | P09 | Texto fijo inexacto | Un literal se copia **exacto** |
| 6 | P11 | `'100'` entre comillas | ✍️ *"Números sin comillas."* |
| 7 | P14 | Columna calculada sin alias | 🏷️ *"El alias dice qué hay dentro."* |
| 8 | P16, P18 | Columnas no pedidas | 📦 *"Entrega exactamente lo que te pidieron."* |
| 9 | Todo el cuaderno | `SELECT *` antes de cada ejercicio | 🔍 *"Explora en otra pestaña."* |

### Hallazgos sorprendentes
- **P10:** `5 / 2 = 2` y `1 / 2 = 0` → ➗ *"Entero entre entero se come el decimal."*
- **P11:** `NULL + 100 = NULL` → ❓ *"No sé + 100 = no sé."*
- **P30:** `WHERE jefe_id = NULL` → 0 filas → 🙋 *"A NULL se le pregunta con IS."*
- **P32 y B.5:** `<>` deja fuera los `NULL` → *"El distinto deja fuera al desconocido."*
